## 🛠️ Built With

- **Flutter** & **Dart** — core app framework

## 🚀 Getting Started

Clone the repo and run it locally:

```bash
git clone https://github.com/Muzamil-Hussain-SE/portfolio
cd portfolio
flutter pub get
flutter run -d chrome
```

### Build for web

```bash
flutter build web
```

The production build will be output to `build/web`, ready to deploy (e.g., to Netlify, Firebase Hosting, or GitHub Pages).
